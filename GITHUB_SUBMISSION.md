# Publish this project on GitHub

1. Sign in to GitHub and create a **new public repository**. Do not add a README, `.gitignore`, or license on GitHub because these files are already in this project.
2. Open a terminal in the extracted `instamart_copilot` folder.
3. Run:

```bash
git init -b main
git add .
git commit -m "Complete Customer Intelligence and Support Copilot capstone"
git remote add origin https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY-NAME.git
git push -u origin main
```

4. Replace the remote URL with the URL of your public repository.
5. Submit the link that points explicitly to the `main` branch:
   `https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY-NAME/tree/main`

Before submitting, open the repository in a private/incognito browser window to confirm that it is public and that all files are visible. The GitHub upload/push has not been performed by this package.
